# 🤝 Apoia+

Conectando quem precisa com quem quer ajudar.

O Apoia+ é uma aplicação desenvolvida para conectar pessoas que precisam de pequenas ajudas no dia a dia com voluntários dispostos a ajudar de forma gratuita.

A plataforma tem como objetivo facilitar o acesso a pequenos serviços e tarefas para idosos e pessoas com deficiência, permitindo que encontrem voluntários de acordo com suas necessidades.

---

## 🎯 Objetivo

Criar uma plataforma simples e acessível que facilite a conexão entre pessoas que precisam de ajuda e voluntários dispostos a contribuir com seu tempo e suas habilidades.

**Exemplos de solicitações**

- 🔧 Pequenos reparos domésticos
- 💡 Troca de lâmpadas
- 🪑 Montagem de móveis
- 🚪 Pequenas manutenções
- 📦 Auxílio para carregar objetos
- 🛠️ Pequenas instalações
- 🏠 Outras tarefas do dia a dia

---

## 👥 Tipos de usuário

 🧓 **Pessoa Assistida**

A pessoa assistida pode:

- Criar uma conta;
- Criar solicitações de ajuda;
- Descrever a tarefa necessária;
- Informar localização e data;
- Visualizar voluntários interessados;
- Escolher um voluntário;
- Acompanhar suas solicitações;
- Encerrar uma solicitação.

🙋 **Voluntário**

O voluntário pode:

- Criar uma conta;
- Informar suas habilidades;
- Visualizar solicitações disponíveis;
- Consultar os detalhes de uma solicitação;
- Candidatar-se para ajudar;
- Acompanhar suas candidaturas;
- Visualizar serviços realizados.

## 🧑‍💻 Engenharia de Software


O desenvolvimento do Apoia+ será realizado utilizando a metodologia ágil Scrum.

O Scrum foi escolhido por permitir um desenvolvimento organizado e incremental, possibilitando que as funcionalidades sejam desenvolvidas e avaliadas ao longo do projeto.

📋 **Organização do desenvolvimento**

O projeto será dividido em Sprints, com cada Sprint tendo um conjunto de atividades e funcionalidades a serem desenvolvidas.

Durante o desenvolvimento serão realizadas:

🎯 **Objetivo do uso do Scrum**

A utilização do Scrum tem como objetivo:

- Organizar as atividades da equipe;
- Dividir o projeto em pequenas entregas;
- Facilitar o acompanhamento do desenvolvimento;
- Identificar problemas durante o projeto;
- Permitir melhorias contínuas;
- Entregar as funcionalidades de forma incremental.


## ⚙️ Funcionalidades

- 🔐 Cadastro e login de usuários
- 👤 Gerenciamento de perfil
- 📝 Criação de solicitações de ajuda
- 🔎 Visualização de solicitações disponíveis
- 🙋 Candidatura de voluntários
- 🤝 Seleção de voluntários
- 📋 Acompanhamento das solicitações
- ✅ Finalização dos serviços
